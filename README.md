# 🗳️ VoteWise – Election Learning Assistant

VoteWise is an interactive Progressive Web App (PWA) designed to help users understand the election process in a simple, engaging, and interactive way.

Built as part of **PromptWars Virtual Challenge**, this project focuses on civic awareness using modern web technologies.

---

## 🚀 Features

### 📚 Interactive Learning

* Step-by-step guide to understand elections
* Covers eligibility, registration, voting process, and results

### 🗳️ Voting Simulation

* Simulate real voting experience
* Select candidates and view live results

### 🧠 Quiz System

* Test your knowledge with MCQs
* Instant feedback and score tracking

### 🤖 AI Assistant (Optional)

* Ask questions about elections
* Simple conversational interface

### 📱 Progressive Web App (PWA)

* Installable on mobile and desktop
* Works offline (basic support)

---

## 🛠️ Tech Stack

* **Framework:** Next.js
* **Styling:** Tailwind CSS
* **Charts:** Chart.js
* **PWA:** Service Worker + Manifest
* **Design:** Google Stitch (Glassmorphism UI)

---

## 🎯 Purpose

Many people find the election process confusing.
VoteWise simplifies it through interactive design and easy explanations.
